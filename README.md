## 💡 About Nexora AI

**Nexora AI** is a web-based AI chat interface project created as part of my journey in learning and practicing web development.

The project focuses on building a clean, modern, and user-friendly chatbot interface with a dark theme and interactive elements.

🚧 **This project is currently under development.** More features and improvements will be added as I continue learning.

## ✨ Features

- Modern dark-themed chat interface
- Responsive layout
- New chat functionality
- Recent chat history
- User and AI message display
- Chat history interaction
- Animated UI elements
- Clean and simple user experience

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Node.js
- Git and GitHub

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/kashavkoli0167-hue/Nexora-AI.git
```
### 2. Open the project folder

```bash
cd Nexora-AI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the project

Check the available scripts in `package.json` and use the appropriate command to start the application.
